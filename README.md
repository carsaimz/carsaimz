## 💻 Plataforma Carsai MZ

A plataforma principal ([carsai.mz](https://carsai.mz)) é construída com tecnologias modernas e disponível em 3 plataformas:

| Plataforma | Tecnologia | Estado |
|-----------|-----------|--------|
| **Web** | Next.js 16 + Vercel | Disponível |
| **Android** | Capacitor 8 | Em desenvolvimento |
| **Windows** | Electron | Em desenvolvimento |

### Funcionalidades da Plataforma

- **Autenticação** — Email/Password, Google, Phone SMS, Anónimo
- **Blog & Fórum** — Publicações, comentários, categorias
- **Serviços & Projetos** — Catálogo e portfólio
- **Orçamentos & Faturas** — Sistema de cotações e pagamentos
- **Suporte** — Tickets de suporte com chat
- **Newsletter** — Subscrição de emails
- **Notificações Push** — Firebase Cloud Messaging
- **Admin Dashboard** — Painel de administração completo
- **8 Idiomas** — PT, EN, FR, ES, DE, ZH, SW, PT-BR

### Stack Tecnológica

| Camada | Tecnologia |
|--------|-----------|
| **Frontend** | Next.js 16, React 19, TypeScript, Tailwind CSS 4, shadcn/ui |
| **Backend** | Next.js API Routes (serverless) |
| **Database** | Firebase Firestore (Spark Plan gratuito) |
| **Auth** | Firebase Auth (Email, Google, Phone, Anonymous) |
| **Mobile** | Capacitor 8 (Android) |
| **Desktop** | Electron (Windows Portable EXE) |
| **CI/CD** | GitHub Actions + Vercel |

## 🚀 Quick Start

```bash
# Clone o repositório
git clone https://github.com/carsaimz/carsaimz.git
cd carsaimz

# Instalar dependências
bun install

# Configurar ambiente (Firebase Admin SDK)
# Copiar .env.example para .env e preencher credenciais
cp .env.example .env

# Iniciar desenvolvimento
bun run dev
```
